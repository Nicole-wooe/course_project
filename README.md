# 💳 Анализ банковских операций

Проект для анализа банковских транзакций: формирование сводки по картам, отображение последних операций и топ-транзакций.

---

## 🚀 Возможности

- 📊 Подсчет суммы операций по каждой карте
- 🔝 Получение топ-5 транзакций
- 🧾 Отображение последних операций по карте
- 👋 Приветствие в зависимости от времени суток
- 🧪 Поддержка тестов (pytest)
